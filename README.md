# 마이 스타 캘린더 (My Star Calendar)

> 최애 덕질(팬 활동)을 한 곳에 모으는 개인화 웹앱 — **https://mystarzip.com**

특정 아티스트 전용이 아니라, 누구나 자기 최애를 등록해서 쓰는 범용 덕질 기록 앱입니다.
핵심은 **개인화**예요. 최애의 상징색을 고르면 그 색으로 앱 전체 테마가 바뀌고, 감성 모드·미니홈피 모드·본문 글꼴까지 취향대로 꾸밀 수 있습니다.

설치형 PWA라 휴대폰 홈 화면에 추가하면 앱처럼 쓰이고, 오프라인에서도 열립니다. 모든 데이터는 **내 기기에만** 저장되며(서버 전송 없음), 별도 회원가입이 없습니다.

---

## 한눈에

- **순수 정적 웹앱** — 빌드·서버 불필요. `index.html` 하나로 동작하고 GitHub Pages로 배포돼요.
- **PWA** — 설치 가능, 오프라인 지원(서비스워커), iOS 스플래시·앱 바로가기·공유 타겟 지원.
- **로컬 저장** — 데이터는 브라우저 `localStorage`, 사진(포카 등)은 `IndexedDB`에 저장. 외부 서버로 나가지 않음.
- **개인화 중심** — 퍼스널 컬러로 전체 테마 변경, 감성 모드 8종, 미니홈피 모드, 본문 글꼴 선택.
- **잡덕 지원** — 최애 여러 명 등록·전환.

## 주요 기능 상세

### 온보딩
최애 사진·이름·덕질 시작일을 등록하고 퍼스널 컬러를 고르며 시작합니다. 사진에서 색을 추출해 퍼스널 컬러로 쓸 수 있고, 건너뛰고 나중에 설정에서 등록할 수도 있어요.

### 홈
덕질 D+일수, 생일·데뷔일 D-카운트다운, 오늘(TODAY) 일정 카드, 티켓팅 초단위 타이머, 이번 달 지출 요약, 나만의 멤버십 카드를 보여줍니다. 생일을 넣으면 별자리·띠·탄생석·탄생화·데뷔 N주년·다음 기념일(100일·N주년) 같은 '별별 정보'도 자동으로 떠요(표시 항목 선택 가능).

### 멀티 캘린더 + 덕질 유형 프리셋
덕질 유형을 고르면 캘린더 카테고리가 그 주제에 맞게 바뀝니다. 프리셋은 **아이돌·배우·버추얼·뮤지컬·스포츠·e스포츠·애니·게임·취미·자유** 10종. 카테고리는 오프라인/온라인으로 나뉘고 색·이름을 직접 편집할 수 있어요. 카테고리 필터, 이모지 스티커, 일정 이미지 카드 SNS 공유를 지원합니다.

### 스케줄러
요일을 여러 개 골라 한 번에 등록, 색상 직접 지정, 자정을 넘는 일정 처리, 고정↔주간 시간표 연동을 지원합니다. 고정·주간·하루·서클(원형) 뷰가 있고 뷰별로 '주말 제외'를 따로 켤 수 있어요.

### 포카 바인더
보유/위시/교환 포토카드를 관리합니다. 이름·앨범 검색, 정렬, 수량 묶기, 앞·뒤 사진(밀어서 뒤집기), 위시 우선순위·가격, 교환 상대·플랫폼 기록, 위시 포카 이미지 내보내기, 반짝이 효과(15종), 통계 요약을 제공합니다.

### 덕질 가계부
월별 지출을 기록하고 카테고리별로 분석합니다. 금액 자동 콤마·'원' 표기, 해외 통화(달러·엔·유로·위안) 환율 환산, 6개월 그래프, 연간 결산을 지원해요.

### 아카이브
오프라인 후기 일기와 링크 보관함(X 직캠, 유튜브 자컨 등)을 모읍니다. 사진은 비율을 맞춰 잘라 올릴 수 있어요.

### 스타일북
최애 착용 아이템을 기록합니다. 브랜드·가격·착용 정보, 위시↔구매 완료 매칭(구매 시 가계부 자동 기록), '룩' 단위 코디 묶기를 지원합니다.

### 그 외
- **잡덕 지원** — 최애 여러 명 등록·전환
- **전체화면 시계** — 한국 시간 + 세계 시간 비교(도쿄·뉴욕·LA 등)
- **음력 생일** — 음력 생일을 올해 양력으로 환산해 계산 (`lunar.js`, 1900–2100)
- **백업/복원** — 전체 데이터를 JSON으로 내보내기·가져오기
- **알림** — 티켓팅·일정·생일/기념일·아침 요약 알림(지원 기기 한정)
- **다크 모드 / 반응형** — 모바일 하단 탭, PC 사이드바

## 꾸미기 (개인화)

설정 → 꾸미기, 또는 '미니홈피 모드' 팝업에서 조절합니다.

- **퍼스널 컬러** — 팔레트·직접 선택·사진 색 추출. 고른 색이 앱 전체 테마(액센트)에 반영돼요.
- **다크 모드**
- **감성 모드 8종** — 기본 · 키치(y2k) · 젤리 · 발레코어 · 드림 · 실버(y3k) · 스타더스트 · 응원봉
- **미니홈피 모드** — 콘텐츠를 레트로 '창'으로 감쌈. 창 스타일 5종(브라우저·폰·메신저·메모장·레트로 윈도우), 창 배치(떠 있는/바닥에 붙는)
- **배경 패턴** — 땡땡이·하트·별·꽃 등 + 패턴 배치·농도(가독성 막) 조절
- **메인 템플릿** — 홈 상단 프로필 영역 스타일
- **본문 글꼴** — 아래 참고

### 본문 글꼴 선택

설정 → 꾸미기(또는 미니홈피 모드)에서 앱 **본문** 글꼴을 고를 수 있습니다(로고·발레코어 제목은 제외).

- **기본** — Pretendard JP (한글·영문·일본어·한자)
- **기기 기본** — 휴대폰에 설정된 시스템 글꼴을 따라감
- **체리한스푼** — 그리운 손글씨체
- **페이퍼로지** — 멀티 굵기 산세리프

선택한 글꼴은 `localStorage`에 저장되고, CSS 변수 `--font-body`로 본문에만 적용됩니다. 고른 글꼴에 없는 글자는 기본 글꼴(Pretendard)로 자동 폴백돼 깨지지 않아요. 굵기가 한 종류뿐인 손글씨체는 브라우저의 가짜 볼드(`font-synthesis`)를 꺼 번짐을 막습니다. 로컬 글꼴 파일은 그 글꼴을 고른 사람만 내려받습니다.

## 기술 메모

- **PWA** — `manifest.json`(설치·앱 바로가기·공유 타겟), `sw.js`(서비스워커). 캐시 전략은 **network-first**: 온라인이면 항상 최신을 받고, 네트워크가 안 될 때만 캐시로 대체. `version.json`·`notices-data.js`는 항상 실시간으로 받습니다.
- **버전 감지** — `version.json` 값이 바뀌면 앱을 켜둔 사용자에게 "새 버전" 배너가 떠요.
- **저장 구조** — 평소 데이터는 `localStorage`, 용량이 큰 사진(포카 등 base64)은 `IndexedDB`에 두고 `localStorage`엔 참조 키만 남겨 저장이 빠르고 가득 차지 않게 합니다.
- **단일 SPA** — 화면 전환·렌더·모달·저장 로직이 모두 `script/app.js`에 들어 있습니다.

## 실행

`index.html`을 브라우저에서 열면 끝. 빌드·서버가 필요 없습니다. 데이터는 브라우저에 저장됩니다.

> 서비스워커·매니페스트까지 동작시키려면 로컬 정적 서버로 여는 걸 권장합니다.
> 예: `python3 -m http.server` 후 `http://localhost:8000` 접속.

## 업데이트(배포) 방법

소식을 올리거나 코드를 고친 뒤 아래 순서로 반영합니다. (자세한 건 `업데이트-방법.md`)

1. **공지 추가** — `script/notices-data.js`의 `NOTICES` 배열 맨 위에 `{ id, cat, date, title, body }` 한 줄 추가. `id`는 이전보다 큰 숫자여야 빨간 점(새 공지)이 떠요. (조용히 고치기만 할 땐 생략 가능)
2. **버전 올리기** — `version.json` 값을 이전과 다르게(날짜+숫자 추천). → "새 버전" 배너 트리거.
3. **캐시 번호 올리기** — `index.html`의 `?v=` 쿼리(`fonts.css`·`style.css`·`app.js`·`notices-data.js`)와 `sw.js`의 `CACHE` 값을 올림. → 바뀐 파일을 확실히 새로 받게 함.
4. 커밋 → 푸시. **새로 만든 파일이 있으면 꼭 같이 스테이지**.
