GUIDE

사용 설명서

처음이라면 여기부터. 기본 사용법과, 종류가 많은 테마(템플릿·감성 모드·미니홈피·퍼스널 컬러)를 한 곳에 정리했어요. 항목을 눌러 펼쳐 보세요.

빠른 시작 화면 둘러보기 기록하기 테마 꾸미기 저장 & 설치
1

빠른 시작

덕질 유형과 최애를 등록해요. 처음 들어오면 안내(온보딩)를 따라가면 돼요. 아이돌·배우·버추얼·뮤지컬·스포츠·e스포츠·애니·게임·취미·자유 중에서 고르면 캘린더 항목이 맞춰져요.

기념일과 퍼스널 컬러를 정하면 D+일수와 테마 색이 자동으로 적용돼요.

메인 화면을 둘러보고, 오른쪽 아래 ＋ 버튼으로 일정·지출·후기·포카를 바로 추가해요.

모든 설정은 나중에 설정이나 더보기에서 언제든 바꿀 수 있어요.

잡덕도 환영이에요. 여러 명을 등록하고 사이드바(PC)나 프로필에서 전환할 수 있어요. 최애마다 색·기록·기념일이 따로 관리돼요. 추가·전환은 설정 → 최애 관리에서 해요.

2

화면 둘러보기

화면 크기에 따라 메뉴 위치가 달라져요.

모바일·태블릿: 아래쪽 탭(메인·캘린더·아카이브·바인더·더보기). 스케줄러·가계부·스타일북·설정 등은 더보기 안에 있어요.

PC: 왼쪽 사이드바에 모든 메뉴가 펼쳐져요.

메인최애 프로필 + D-DAY·이번 주·오늘 일정·시계·음악 등 위젯 대시보드. 블록은 직접 편집해요.
캘린더컴백·콘서트·티켓팅 같은 일정과 기념일을 달력으로 관리.
스케줄러고정(매주 반복)·주간(그 주 일정)·하루(24시간 원형) 뷰로 일정을 짜요.
아카이브다녀온 기록(후기 일기)과 아껴둔 링크 보관함.
포카 바인더수집한 포토카드를 보유·위시·교환 중으로 정리.
덕질 가계부지출 기록·월별 그래프·올해 통계로 행복 비용을 한눈에.
스타일북최애 착용 아이템과 내 구매를 매칭(전체·위시·구매 완료).
설정테마·최애 관리·알림·데이터 백업 등 모든 환경설정.

메인 위쪽의 홈 편집을 누르면 위젯 블록(시계·음악·D-DAY 등)을 드래그로 순서 변경하거나 ✕로 숨길 수 있어요. 숨긴 블록은 아래 '숨긴 블록'에 모여서 다시 추가할 수 있고, 완료를 누르면 저장돼요.

3

기록하기

오른쪽 아래 ＋ 버튼을 누르면 어느 화면에서든 바로 추가할 수 있어요.

일정 등록캘린더에 컴백·티켓팅 등 일정을 추가.
지출 기록가계부에 굿즈·앨범 등 지출을 기록.
후기 쓰기아카이브에 다녀온 기록(일기)을 남겨요.
포카 추가바인더에 포토카드를 등록.
스타일 아이템스타일북에 착용/구매 아이템을 추가.

메인의 시계를 탭하면 전체화면 시계로 커져서 티켓팅 때 시간을 보기 좋아요(서버 시간 보정도 가능). 설정에서 티켓팅 10분 전 알림을 켜두면 탭이 열려 있을 때 알려줘요.

4

테마 꾸미기

앱 전체 포인트 색이에요. 설정 → 퍼스널 컬러 테마에서 팔레트를 고르거나 직접 색을 입력할 수 있어요. 최애 사진에서 색을 추출해 자동으로 테마를 맞추는 기능도 있어요. 색 하나만 바꾸면 버튼·강조·아이콘 색이 한 번에 바뀝니다.

메인 화면 상단 프로필의 배치 스타일이에요. 설정 → 메인 템플릿에서 바꿔요.

클래식사진과 정보를 좌우로 나란히. 깔끔한 기본형.
프로필형넓은 커버 + 동그란 프로필. SNS 느낌.
포스터사진을 큼직하게 깔고 이름을 얹은 화보형.
폴라로이드즉석사진처럼 살짝 기울어진 감성 프레임.
미니멀사진 없이 텍스트 위주로 가볍고 단정하게.

화면 전체 분위기를 바꾸는 무드 테마예요(하나만 켜져요). 설정 → 감성 모드에서 고르세요.

기본군더더기 없는 깨끗한 화면.
키치알록달록 통통 튀는 Y2K 감성.
젤리말랑하고 투명한 젤리 같은 질감.
발레코어부드러운 파스텔의 우아한 발레 무드.
드림몽환적이고 꿈결 같은 분위기.
실버미래적인 메탈릭 Y3K 룩.
스타더스트밤하늘 자체가 배경이 되는 별가루 모드.
응원봉화면을 어둡게 만들어 응원봉처럼 빛나는 모드.

※ 스타더스트·응원봉은 배경 자체가 특수해서 아래 '배경 패턴'은 잠겨요.

화면 바탕에 깔리는 작은 무늬예요. 설정 → 감성 모드 안의 배경 패턴에서 고를 수 있고, 종류는 기본·땡땡이·하트·반짝이·별·꽃·클로버·리본·체리·사과·구름·물결·마름모·사선·지그재그·격자·체크가 있어요.

하트·반짝이·별·꽃·클로버·체리·사과·구름·마름모 패턴은 배치(흩뿌림 / 사선)도 바꿀 수 있어요. 콘텐츠 배경 농도를 올리면 패턴 위에서도 글씨가 또렷해져요.

화면을 추억의 '창'으로 감싸는 모드예요. 설정 → 미니홈피 모드 또는 더보기에서 켜요. 창 스타일을 고르면 바로 켜집니다.

브라우저옛날 웹 브라우저 창 느낌.
폰휴대폰 화면 프레임 안에 담긴 모습.
메신저메신저 대화창 같은 레이아웃.
메모장메모장 앱처럼 심플한 창.
레트로 윈도우옛 PC 운영체제 창 그대로의 감성.

창 배치는 떠 있는 창 / 바닥에 붙은 창 중에 고를 수 있어요.

다크 모드는 어두운 화면으로 전환해요. 사이드바·모바일 헤더·더보기·설정 어디서든 켤 수 있어요.

화면 정렬(PC)은 콘텐츠를 왼쪽 또는 가운데로 둘지 정해요. 설정에서 바꿉니다.

5

저장 & 설치

모든 기록은 지금 쓰는 브라우저 안(기기 저장소)에 저장돼요. 서버로 보내지 않아 다른 사람은 볼 수 없고, 이 기기·이 브라우저에만 남아요. 그래서 브라우저(크롬/엣지 등)마다 기록이 따로예요.

설정 → 데이터 → JSON 백업으로 파일을 내보낸 뒤, 새 기기에서 복원하면 그대로 옮겨와요. 브라우저 데이터를 지우기 전에도 백업해 두면 안전해요. 설정의 저장 보호를 켜면 브라우저가 함부로 지우지 않도록 요청할 수 있어요(지원 브라우저).

모바일 브라우저의 '홈 화면에 추가'를 누르면 앱처럼 아이콘으로 띄워 쓸 수 있어요. 설치해서 쓰면 더 안정적이에요.
