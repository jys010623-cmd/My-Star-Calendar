# 마이 스타 캘린더 (My Star Calendar)

덕질(팬 활동) 스케줄 기록·관리 웹앱 — **초안 (draft v0.1)**

특정 아티스트 전용이 아닌, 누구나 자기 최애를 등록해서 쓰는 범용 덕질 기록 앱.
핵심은 **사용자 개인화(커스텀 자유도)** — 최애의 상징색으로 앱 전체 테마가 바뀝니다.

## 주요 기능

- **온보딩**: 최애 사진·이름·덕질 시작일 등록, 퍼스널 컬러 선택 (사진에서 색 추출 가능)
- **메인**: D+일수, 생일/데뷔일 D-카운트, TODAY 일정 카드, 티켓팅 초단위 타이머, 이번 달 행복 비용, 나만의 멤버십 카드
- **멀티 캘린더**: 컴백/콘서트/티켓팅/생카/방송/발매/개인 카테고리 색상·필터, 이모지 스티커, 일정 SNS 공유
- **포카 바인더**: 보유/위시 포토카드 컬렉션
- **덕질 가계부**: 월별 지출 기록, 카테고리 분석, 6개월 그래프
- **아카이브**: 오프라인 후기 일기 + 링크 보관함 (X 직캠, 유튜브 자컨 등)
- **스타일북**: 최애 착용 아이템 기록, 위시 ↔ 구매 완료 매칭
- **잡덕 지원**: 최애 여러 명 등록·전환
- 다크 모드, 반응형 (모바일 하단 탭 / PC 사이드바), JSON 백업·복원

## 실행

`index.html`을 브라우저에서 열면 끝. 빌드·서버 불필요.
데이터는 브라우저 localStorage에 저장됩니다.

## 구조

```
index.html        앱 전체 마크업 (SPA)
css/fonts.css     Pretendard 폰트
css/style.css     테마 변수 + 전체 스타일
script/app.js     앱 로직 (저장, 렌더링, 모달)
```

## 로드맵 아이디어

- 서버 시간 동기화 티켓팅 타이머
- 홈 화면 위젯 (네이티브 앱 버전)
- 생카 지도 연동
- 일정 이미지 카드 생성 후 SNS 공유
